# Design surfaces

What the console must render, surface by surface, and which visual classes and tokens each one
requires. The stylesheet this contract describes ships: `crates/openkite-ui/assets/console.css`,
generated by `crates/openkite-ui/assets/build_console_css.py`. Every selector named below is defined
in that sheet today; § [Retired vocabulary](#retired-vocabulary) lists the reference names the
shipped console does not use, so a stale name cannot quietly come back.

## Sources of record

- `crates/openkite-ui/assets/console.css` — the shipped sheet, and the authority for what a surface
  is called. Generated, never hand-edited.
- `docs/reference/opendesign-console/` — the prototype, vendored byte-identical to the live design
  (console, charts and workloads sheets). Design intent and line anchors live here; it is not product
  code.
- `DESIGN.md` — the token set, its reference values and the contrast floor.
- The rebuild spec — which surfaces are in scope now, which are deferred, and the parity gate.

Line numbers are deliberately absent. The reference is a live artifact that changes; selectors and
class names are the stable part.

## Deltas from the reference worth keeping

**Sidebar frost.** The reference frosts `.sidebar` and keeps section titles on `muted`. The console
keeps that, and keeps the healthy-cluster dot on `subtle` rather than the reference's `success`, so a
healthy cluster does not read as an alert.

**Pull-to-refresh.** The reference ships the indicator as static markup. The console needs it live:
`.pull-indicator` with `.show` driving the reveal, no inline styles.

**Namespace bar.** The strip, the search circle and the clear affordance are new design, not reference
carry-over. Namespace chips must filter in place without a route change.

**Bulk-select.** The bar and the danger button follow the reference. The tri-state header checkbox,
shift-range selection and the `.sel-count` reason line are console additions.

**Inspector tabs.** The reference's tab vocabulary is kept as `.insp-tabs` / `.insp-tab`; tab content
is per-kind and therefore specified by the kind catalogue rather than here.

**Settings.** The reference opens a centred dialog. The console opens a right-hand pane (`.set-pane`
behind `.set-scrim`) holding one flat list of the 24 presets — see `DESIGN.md` § Appearance. There is
no second entry point: the topbar `.theme-toggle` toggles the same pane, and the phone layout presents
it as a sheet.

## Glass

Glass is unconditional, not a mode. The sheet and the markup carry no `data-glass` attribute, no glass
switch and no reduced-glass surface set: `prefers-reduced-transparency` and `prefers-contrast` change
tokens (`--glass-alpha`, `--glass-hair`, `--scrim-tint`), never which surfaces are glass. A capture
taken with the mockup's `data-glass="off"` flag is a comparison artefact, not a product state, and
must not be reintroduced as one.

## Not in this document

Command palette scope chips, drag-and-drop column reordering and the dock tab strip evolve past the
reference. They are specified by their own tickets; this file only fixes the classes they must reuse
(`.search-sheet`, `.col-menu`, `.dock-tabs`).

## Status vocabulary

- **deferred** — out of the first release, named with the spec row that defers it.
